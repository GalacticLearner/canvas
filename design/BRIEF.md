# Canvas design brief

## Context and direction
Impeccable 4.8.0 context/init/new-work/craft-floor applied to the client only. The plan supplies the audience, tone, stack and task; its no-questions/delegated-decisions instruction overrides skill interview/selection rounds. App UI is code-led. No visual authority existed.

Seven grounded directions considered: classroom handout, library index, field notebook, workshop pinboard, architecture studio critique, scientific journal, exhibition wayfinding. Assigned candidate 5 (seed:5cee3826930bdbd4): architecture studio critique. Translate only type, palette, density and one signature interaction, retaining familiar editor controls. Warm paper, forest ink, ochre selection, generous drawing space. Signature: frame outlines and the Frames dock act as synchronized slide-navigation regions, allowing a classroom board to become a presentation.

Challengers: variable-font specimen declined (giant glyphs obscure the workspace); retain its disciplined type hierarchy. Acetate manual declined (transparent leaves reduce bright-room clarity); retain compact tab organization. Bitmap specimen declined (long-session legibility); retain density discipline. Convention catalog competitive for frame thumbnails but not primary editor clarity. Orienteering map declined (terrain semantics conflict with authored canvas colors); retain clear symbols plus text. Midnight transit diagram competitive for connectors but not the neutral canvas; retain visible connection states.

## Screens and flows
Connect: local IP, username, Create/Join tabs, name/code/password, approval/default-role controls, discovery, recents, local board/open. Primary action enters a board; errors remain beside the action. No marketing claims or synthetic testimonials.

Board: top session bar, left grouped tool rail, contextual property strip, two canvas layers, optional right dock, bottom viewport controls/status. Canvas takes remaining space. Dock tabs: Chat, People, History, Frames. Below 1280 px it overlays instead of squeezing canvas. Board name, code, role and transport status remain readable.

Create → room owner; Join → optional password challenge → optional approval waiting → board. Reconnect keeps drawing and announces pending count. Local mode offers save/open/share. Presentation uses ordered frames and explicit following state. Versions offer preview before restore. Room settings are owner-only. Export chooses format and scope. Shortcuts are one dismissible overlay.

## States
Empty canvas teaches first gesture; no discovered servers gives manual IP entry. Loading/join-pending state stays on Connect. Rejected operations show cause. Offline state persists pending actions. Disabled controls explain permissions. Names truncate visually with complete accessible labels; chat wraps. Focus rings remain visible in both themes. Reduced motion removes transitions.

## Components
Button, IconButton, Tooltip, Popover/Menu, Tabs/Segmented, Switch, Slider, ColorSwatchPicker, Avatar, Badge, Toast, Dialog, Kbd, ScrollArea, ResizableDock. Semantic buttons/labels/ranges; Escape closes overlays. UI scaling 100/125/150%; minimum target 36 px. Light, dark, high-contrast themes. Keyboard shortcuts follow plan.md.
